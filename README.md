# vix-game

Vix game project generated by `vix new --game`.

This project uses the Vix game foundation:

- `App`
- `GameRuntime`
- `Scene`
- `SceneManager`
- `GamePackage`
- `vix.app`
- `game.package.json`

## Quick start

```bash
cd vix-game
vix build
vix run
```

Expected output:

```text
Main scene loaded
frame: 0
frame: 1
frame: 2
frame: 3
frame: 4
frame: 5
```

## Project layout

```text
assets/             Game assets
game.package.json   Game package metadata
README.md           Project documentation
src/main.cpp        Game entry point
vix.app             Vix application manifest
vix.json            Vix project metadata and tasks
```

## Game package

`game.package.json` describes the game project.

It contains:

- game name
- version
- entry scene
- asset root
- output directory
- scene list
- asset list

## Assets

Put your game assets in:

```text
assets/
```

The Vix game export pipeline can scan this directory and write exported asset metadata into `export.json`.

## Build manifest

This project uses `vix.app` as its application manifest.

The manifest links:

- `vix::game`
- `vix::io`

It also declares resources:

- `assets=assets`
- `game.package.json=game.package.json`
